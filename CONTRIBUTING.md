# Contributing to CreationsForge

Report bugs and suggest features through the [GitHub issue tracker](https://github.com/monster-cookie/CreationsForge/issues). For a bug report, include your application version, operating system, affected game, steps to reproduce, and expected and actual results. Do not include credentials, private data, or game files.

Contributor setup, architecture, development procedures, and technical research are maintained in the [CreationsForge engineering index in Plane](https://app.plane.so/venworks/projects/874929c3-5c2e-4f0f-b0b3-fbef7b74bc5e/pages/179d4a01-77d8-45a4-ba5a-9d8d1b0d8ad5). These pages require the appropriate Plane workspace access; contact the maintainers if you need access to contribute.
