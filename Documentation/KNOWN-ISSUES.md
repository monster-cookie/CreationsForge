# Known Issues

- Only a subset of the record types are supported at this time. 
  - The supported record types are:
    - FormList (FLST)
    - GameSetting (GMST)
    - Global (GLOB)
    - MiscItem (MISC)
    - Keyword (KYWD)
    - NPC (NPC_)
    - ActorValueInformation (AVIF)
    - MagicEffect (MGEF)
    - Perk (PERK)
