# Roadmap

These are the planned features for the project.

# 1 Month

- [ ] Support for the remaining Starfield Record Types

# 3 Months

- [ ] Export/Import of plugins via spriggit (or at least compatible with it)
- [ ] Export/Import of records via spriggit (or at least compatible with it)
- [ ] Full validation of all supported record types against Spriggit/xEdit]

# 6 Months
- [ ] Record editing (copying, pasting, creating, deleting)
- [ ] Saving plugins
- [ ] Support for creating plugins
- [ ] Support for creating patches

# Long Term

- Open Source local LLM for automatic patch creation
