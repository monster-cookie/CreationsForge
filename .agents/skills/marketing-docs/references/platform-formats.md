# Optional publishing-platform formats

Use this reference only when the requested destination is Nexus Mods or Bethesda Creations. For other destinations, follow their own documented formats and project conventions.

## Nexus Mods

Use only supported Nexus BBCode and preserve balanced tags, valid links, images, lists, emphasis, quotes, and code blocks. Do not invent tags or convert to Markdown unless requested. Check the actual page preview when available; balanced markup alone does not prove the page renders correctly.

## Bethesda Creations

Use only syntax known to work in the project's target restricted Markdown dialect. Do not assume full CommonMark or GitHub-Flavored Markdown support; use safe plain text when support is uncertain. Verify the destination preview when available and report unverified rendering separately.

## Preserve the content

When converting formats, preserve meaning, links, emphasis, lists, images, code, credits, and ordering where supported. Do not rewrite accurate wording merely to change markup. Report unsupported formatting and any unverified platform behavior.
