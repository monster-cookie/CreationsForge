# Starfield Record Compare Engine

This application is a Mutagen-based plugin inspection and comparison tool. It combines a UI with a backend analysis engine to load Bethesda plugin files, parse their record hierarchy, and present the results in an easy-to-navigate format.

The tool focuses on helping mod authors and developers inspect plugin record, review master overrides, browse records by type, and compare record hierarchies between plugins. It is intended to support debugging, validation, compatibility review, and general plugin analysis workflows.
